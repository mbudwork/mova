# MOVA — VIDEO BRIEF v2

Два ролика для разных задач, оба переписаны под hero V2 — момент прослушивания
теперь стоит в самом верху страницы, и видео должно продолжать этот же
нарратив, а не открывать новый.

Все немецкие фразы — настоящий production-контент, не выдуманы для съёмки.

### Safe area для Reels/Stories

Верх — 250 px свободны (аватар/ник), низ — 420 px свободны (подпись, CTA-плашка

1080×1920. Сообщение должно читаться без звука.

## Соответствие лендингу (message match)

Реклама и лендинг используют **одну и ту же немецкую фразу и один и тот же
визуальный момент** — экран «Что сказал прораб?» с тремя вариантами ответа.
Посетитель, кликнувший по рекламе с этим крючком, должен увидеть на лендинге
буквально то же самое действие, а не другую фразу и не другой интерфейс.

## Какие экраны нужны из приложения

1. Экран MOVA-момента — «Что сказал прораб?», кнопка ▶, три варианта до ответа.
2. Тот же экран после ответа — ✓/✕, раскрытый немецкий, перевод.
3. `/app` — главный экран, шкала прогресса.
4. `/app/profession` — модуль специальности.
5. Safari → «Поделиться» → «На экран «Домой»».

Несуществующие экраны не рисуются — если кадра из приложения нет, сцена
вырезается.

## Чего не будет

Отзывов, лиц «учеников», выдуманных цифр, обратного отсчёта, обещаний
беглого владения языком.
