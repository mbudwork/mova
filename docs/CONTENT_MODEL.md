# CONTENT MODEL

## Правило, определяющее всё остальное

Мы тренируем понимание на слух, а не память на предложения. Значит фраза —
не строка, а структура, из которой можно собрать НОВУЮ проверочную задачу.

## Уровни модели

### 1. Phrase

Единица контента. Немецкий текст — source, переводы — в `phrase_translations`.

Два варианта рядом с каноническим текстом:
- `formal_variant` — как в учебнике (Sie-форма);
- `natural_variant` — как реально говорит полир.

### 2. PhraseFamily

Одна коммуникативная интенция в четырёх регистрах:

| register_level | Пример |
|---|---|
| 1 | Bitte holen Sie die Wasserwaage. |
| 2 | Hol bitte die Wasserwaage. |
| 3 | Hol mal die Wasserwaage. |
| 4 | Hol mal kurz die Wasserwaage rüber. |

Система знает, что это одно и то же. Пользователь проходит семью снизу вверх:
сначала понимает чистую форму, потом — ту, что услышит на объекте.

### 3. PhraseComponents

Семантическая разметка предложения:

```
Schneid die Platte fünf Zentimeter kürzer und stell sie danach hier hin.
ACTION       OBJECT      MEASUREMENT    QUALITY      SEQUENCE  ACTION  LOCATION
```

**Пользователь этой разметки не видит никогда.** Она нужна движку, чтобы
спросить «что именно нужно отрезать?» или «на сколько короче?», а не чтобы
показать разбор предложения на экране.

### 4. Content Template Engine

Проверка понимания вместо памяти: фраза, которую пользователь никогда не
слышал, собранная из уже изученных компонентов.

```
Шаблон:  Schneid {object} {measurement} kürzer.
object:       die Platte | das Profil
measurement:  fünf Zentimeter | zehn Zentimeter
```

**Критическое ограничение.** `template_slot_options.german_surface` хранит
готовую словоформу для конкретной позиции слота — здесь аккузатив. Движок
только конкатенирует. Он не склоняет, не согласует и не изобретает немецкий:
иначе `Schneid der Platte` попадёт пользователю и будет заучено как норма.

Расширение шаблона на новую позицию = новый набор утверждённых surface-форм,
а не переиспользование старых.

## Прогрессия обучения

```
Exposure          немецкий + аудио + русский
      ↓
Recognition       немецкий + аудио
      ↓
Listening         только аудио
      ↓
Natural           natural_variant, тот же смысл
      ↓
Transfer          новая комбинация из известной лексики
```

Просмотр карточки не считается изучением. Состояние хранится в
`phrase_progress.state`, ошибки возвращаются чаще.

## Приоритеты контента

| Приоритет | Что это |
|---|---|
| SURVIVAL | Без чего нельзя отработать смену: «осторожно», «не трогать», «где именно?» |
| WORKING CORE | Частые команды: принести, переделать, размер не тот, сначала эту стену |
| TRADE | Лексика конкретной профессии |

300 выверенных единиц лучше 1000 сгенерированных. Приложение production-контент
не создаёт: он приходит из отдельного процесса через пайплайн проверки.

## Пайплайн проверки

```
DRAFT → LANGUAGE REVIEW → TRADE REVIEW → [SAFETY REVIEW] → APPROVED
      → AUDIO GENERATED → AUDIO APPROVED → PUBLISHED
```

Гарантии, вшитые в БД, а не в UI:
- `draft` не возвращается из базы обычному пользователю ни в одной проекции;
- `safety_sensitive` без `safety_approved` не может получить статус `approved`
  (check-constraint), и не виден пользователю (RLS).

## Источник нового контента

`search_queries` с `results_count = 0` — очередь на написание. Это реальные
фразы, которые люди искали и не нашли, то есть доказанная потребность, а не
догадка редактора.
